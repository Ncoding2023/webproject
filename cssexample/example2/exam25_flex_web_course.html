학습 과정 소개

이 과정에서는 웹 개발의 핵심 기술인 HTML, CSS, JavaScript를 학습합니다. 각 기술의 기본 개념과 활용 방법을 익히고, 실습을 통해 실제 웹 페이지를 만들어봅니다.

아래 카드 목록은 웹 개발의 기본이 되는 세 가지 기술에 대한 간략한 설명입니다.

웹 개발 핵심 기술

HTML

HTML은 웹 페이지의 구조를 만드는 마크업 언어 제목, 문단, 목록, 이미지, 링크, 표와 같은 기본 요소를 작성

학습 단계: 기초
  • HTML 기본 구조 이해하기
  • 시맨틱 태그 활용하기
  • 폼 요소와 입력 필드 만들기
  • 이미지와 링크 삽입하기

CSS

CSS는 웹 페이지의 디자인을 담당하는 언어 글자 색상, 배경색, 글꼴, 여백, 배치 등을 설정하여 화면을 꾸밈

학습 단계: 기초 ~ 중급
  • CSS 선택자와 속성 이해
  • 박스 모델과 레이아웃 구성
  • Flexbox와 Grid로 배치하기
  • 글자와 문단 스타일 적용

JavaScript

JavaScript는 웹 페이지에 동작을 추가하는 언어 버튼 클릭, 입력값 처리, 화면 변경 등을 구현

학습 단계: 중급
  • 변수와 자료형 이해
  • 조건문과 반복문 사용
  • 함수 정의와 호출
  • DOM 요소 제어
