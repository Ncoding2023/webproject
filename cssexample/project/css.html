CSS 주요 개념

CSS(스타일시트)는 웹 페이지를 예쁘고 보기 좋게 꾸미는 기술이에요. 아래 내용을 차근차근 익혀봐요!

  • 박스 모델: HTML 요소는 모두 박스에요. 테두리(border), 안쪽 여백(padding), 바깥 여백(margin)으로 구성돼요.
  • 배경: 배경 색, 배경 이미지, 반복 여부 등 다양하게 꾸밀 수 있어요.
  • 색상: 텍스트, 배경, 경계선 등 색상을 자유롭게 조절해요.
  • 레이아웃: 플렉스박스, 그리드로 요소 배치를 담당해요.
