JavaScript

자바스크립트는 웹 페이지를 더 멋지고 재미있게 만들어 주는 프로그래밍 언어입니다.

여기서는 기본 개념과 간단한 예제를 함께 공부해봐요!

주요 개념

  • 변수: 데이터를 저장하는 상자예요. let, const가 대표적이에요.
  • 함수: 일을 수행하는 코드 묶음. 필요할 때 호출해 사용해요.
  • 조건문: 상황에 따라 다른 동작을 하게 해줘요. if, else가 있어요.
  • 반복문: 같은 작업을 여러 번 반복할 때 사용해요. for, while 등이 있죠.

간단한 예제

    // 버튼 누르면 인사말 출력하는 코드
    function sayHello() {
      const name = prompt('이름을 알려주세요!');
      if(name) {
        document.getElementById('output').textContent = name + '님, 안녕하세요!';
      } else {
        document.getElementById('output').textContent = '이름이 없으면 인사할 수 없어요!';
      }
    }
