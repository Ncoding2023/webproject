홈 HTML CSS JavaScript 학습 갤러리

학습 주제 갤러리

Grid Layout을 사용하여 여러개의 항목을 일정한 간각으로 배치하는 갤러리 예제입니다.

📄

HTML

HTML은 웹 페이지의 구조를 만드는 마크업 언어 제목, 문단, 목록, 이미지, 링크, 표와 같은 기본 요소를 작성

🎨

CSS

CSS는 웹 페이지의 디자인을 담당하는 언어 글자 색상, 배경색, 글꼴, 여백, 배치 등을 설정하여 화면을 꾸밈

⚙️

JavaScript

JavaScript는 웹 페이지에 동작을 추가하는 언어 버튼 클릭, 입력값 처리, 화면 변경 등을 구현

📦

박스 모델

박스 모델은 HTML 요소가 차지하는 영역을 content, padding, border, margin으로 설명합니다.

🧭

Flex Box

Flex Box는 요소가 한 방향으로 배치하고 정렬할 때 사용하는 CSS 레이아웃 방식입니다.

⬜

Grid Layout

Grid Layout은 웹 페이지를 행과 열로 나누어 요소를 배치하는 2차원 레이아웃 방식입니다.
